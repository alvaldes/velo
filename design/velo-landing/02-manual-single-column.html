velo a terminal music player · rust · mit

A player, a library, and nothing running behind them.

velo indexes the music you already have, from the files' own tags, and plays it gaplessly inside the terminal you are already in. One binary. No daemon, no server, no account, no usage data.

Install

1. A prebuilt binary, if your platform is on the list

Release archives are built by CI for x86_64-unknown-linux-gnu, aarch64-unknown-linux-gnu, x86_64-apple-darwin and aarch64-apple-darwin.

  1. Take velo-<tag>-<target>.tar.gz from Releases.
  2. Unpack it anywhere stable: tar -xzf velo-*.tar.gz -C ~/.local/bin.
  3. Make sure that directory is on your PATH, then run velo.

2. From a clone, with cargo

# needs Rust 1.88 or newer git clone https://github.com/alvaldes/velo cd velo cargo install --path .

On Linux the audio stack wants the ALSA development headers; the toolchain covers everything else. cargo install velo will work once the crate is published.

What you get: a single executable. Its first launch writes its own comments to ~/.config/velo/config.toml and a themes/ folder beside it, and tells you how to point it at a music folder — L in the interface, or --library on the command line.

First run

velo --library ~/Music --index # point, index velo --library ~/Music # the browser, indexed in the background velo song.flac song.mp3 # play exactly these, gaplessly velo --play song.flac # play and exit when it ends velo --info song.flac # format, frames, length

The whole interface, from the keyboard

Four numbered views — artists, albums, tracks, genres — with enter to descend and to play, / to search anything, tab for the queue, space to pause, ←/→ to seek, v to change the spectrum, ctrl+p for settings and a theme picker, ? for the full key map. A cover card describes the track that plays; d lists the machine's output devices.

What it does with the sound

gapless
The next track is decoded before the current one ends.
replaygain
Track or album gain, read from the files' own tags.
bit-perfect
The device reopens at the file's rate, volume pinned; a rate the device cannot take falls back to converting, and says so once.
mono
A session downmix, refused under bit-perfect rather than faked.
radio
The Radio Browser directory and the cliamp channels: favourites, pinned places, live ICY titles, and a refusal instead of a hang on what cannot play.
subsonic
Navidrome and friends, browsable and searchable, media keys and scrobbling included.
Privacy, in one line: velo sends no usage data. It asks the network only for what you pointed it at — a station, a directory, your own server. There is no analytics endpoint to opt out of.

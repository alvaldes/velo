A music player that lives in your terminal,
from one Rust binary.

Point it at your music folder and velo indexes it from the files' own tags — artists, albums, tracks, genres — then plays it gaplessly, draws the cover art, and takes over the window with a keyboard-driven interface. No daemon, no server, no account, no telemetry.

Install

velo-<tag>-<target>.tar.gz

Download the archive for your platform from Releases, unpack it, and put velo on your PATH. Built for x86_64/aarch64 Linux (gnu) and macOS (darwin).

git clone https://github.com/alvaldes/velo && cd velo && cargo install --path .

Needs Rust 1.88 or newer. Building the audio stack wants the ALSA headers on Linux; everywhere else the toolchain is enough.

cargo install velo

Once it is on crates.io.

What's inside

01Gapless, honest playback

The next track is decoded before this one ends. ReplayGain by track or album, a real bit-perfect mode that reopens the device at the file's own rate, and a mono downmix that refuses to lie when it cannot.

02Your library, from its own tags

An index built from the files themselves: browse by artist, album, track or genre, with fuzzy search and an editable queue that reads like the list you built.

03Cover art in the terminal

The artwork of what plays, decoded and drawn where your terminal can show images — and a spectrum in nine shapes where it cannot, or when you would rather see the music.

04Radio, the way it should feel

The Radio Browser directory plus the cliamp channels: favourites and pinned places, live ICY titles, a ● live row that reads as a stream and refuses what cannot play instead of hanging.

05Themes as files

velo wears the terminal's own palette if you want it to, ships a factory palette of its own, and takes any TOML theme you drop beside your config — hand it to another person, they get your colours.

06One binary, nothing behind it

No daemon, no server, no account, no usage data leaving your machine. The interface and the audio live in the same process you started.

Navidrome and friends too. Point velo at a Subsonic-compatible server to browse and search the remote library, with media keys and scrobbling wired in.
